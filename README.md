# G · ONLINE

Живая партия на [OGS](https://online-go.com): вход, доска и часы, соперника подбирает OGS, итог и территория.
Страница целиком работает в браузере и говорит с OGS напрямую: вход по паролю OGS, игра по сокету OGS
(протокол — из открытой библиотеки OGS [goban](https://github.com/online-go/goban), Apache 2.0).
Пароль нигде не хранится; в браузере остаётся только игровой ключ OGS на 30 дней.

Собрано `npm run build:pages` из проекта online; здесь только готовая страница.
